# 原型（Bloomberg-terminal 风格）

本目录提供一个本地可打开的静态 HTML 原型，用于验证“指数 UI 架构/信息密度/交互”。

## 打开方式

- 直接用浏览器打开：`prototype/index.html`
  - 或从 `prototype/help.html` 查看整体界面架构与快捷键

## 页面

- `prototype/index.html`：榜单（右侧 hover 上下文 + 底部 ticker）
- `prototype/entity.html`：实体详情（SNW 历史 + components 分解）
- `prototype/help.html`：界面架构/命令/快捷键

## 快捷键（demo）

- `Ctrl/⌘ + K`：Command Palette
- `I`：回到榜单
- `?`：帮助页
