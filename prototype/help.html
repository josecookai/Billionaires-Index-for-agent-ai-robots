UI ARCH

三栏结构（Bloomberg-terminal 风格）：
Left 导航/模块
Center 主视图（表格/图）
Right 上下文/解释/快捷动作
底部 ticker：用于“实时感”的轻量信息流。

KEYBOARD-FIRST PROTOTYPE

Dense, auditable, explainable SNW index UI.

COMMANDS

index
打开榜单（SNW Index）
open <id/name>
打开实体，例如 open e-003 / open mosaic
find <text>
搜索（demo：以 URL 参数实现）
help
打开帮助页

DESIGN TOKENS

字体：主 UI 使用 sans；数据/表格/命令行使用 monospace。
颜色：背景深色；强调色 amber（计算/告警）；上涨 green；下跌 red；链接蓝。
密度：表格为主，图表为辅（sparkline/小图），右侧解释面板常驻。
